# SINOTRUK TEAM 全站视觉重构基线

## 设计定位

- 面向国际商用车采购的工业视觉网站，不采用传统企业官网或纯文字 B2B 页面。
- 核心感受：车辆真实、工程感、信息可信、采购路径清晰。
- 视觉语言：深石墨底色、暖白内容面、矿物橙作为唯一行动色；大幅真实产品图与细节图承担主要叙事。
- 禁止：纯文字分类卡、渐变文字、假数据、无依据的品牌承诺、外部图库素材、廉价占位图。

## 设计令牌

| 角色 | 新色值 | 用途 |
| --- | --- | --- |
| Ink | `#202321` | 深色文字、暗色图片区、页脚 |
| Canvas | `#F1F0EB` | 页面底色 |
| Surface | `#FBFAF6` | 内容卡片、表单 |
| Steel | `#66706C` | 辅助文字 |
| Signal | `#D95D28` | 询盘、重点链接、选中状态 |
| Signal Dark | `#A8421A` | 悬停与高对比行动色 |

## 图片规则

1. 首页首屏、分类、产品、配件、新闻、关于与服务页均必须有真实图片。
2. 分类页优先采用 `public/images/products` 中原有分类主图；产品与配件优先使用自身主图、图库或性能图。
3. 图上文字必须有暗色遮罩或独立信息面，保证对比度；图片仅作真实内容展示，不伪造认证、客户或交付事实。
4. 首屏图片可裁切但不得拉伸；目录图使用固定比例；详情图支持完整查看。

## 页面结构

- 首页：全幅车型主视觉、带图分类、采购方式、应用场景、新闻图文、RFQ 收口。
- 目录页：图像优先的筛选与产品卡；过滤工具固定、结果可比较。
- 详情页：产品大图、规格和配置确认、细节图库、采购行动区。
- 新闻页：封面图、来源/类别/日期、可读的文章版式。
- 后台：操作密度高于展示性，统一新色彩令牌、图片预览、明确状态和保存反馈。

## 保护边界

- 不删除或改写现有产品、配件、分类、图片、ID、slug、公开 URL、SEO 和询盘数据。
- 不改变飞书通知逻辑。
- 所有新视觉必须通过移动端、键盘焦点、图片 alt、构建和目录完整性校验。
